# ideal-journey

## 熊林洋的手绘作品集

七本手绘书组成首页，AI创意、关于我、AI产品三本支持抽出、旋转、打开和阅读。

- AI创意：保留 PDF 原始排版，附两个按需加载的视频，侧边“图片／视频”便签支持跳转。
- 关于我：个人介绍、教育与实践经历、专业技能和联系方式。
- AI产品：AI 数理实验室项目展示与实验演示视频。

### 本地预览

安装 Node.js，在仓库目录运行：

```sh
node server.mjs
```

浏览器打开 http://127.0.0.1:4173/ 。请通过 HTTP 服务访问，不要直接双击 HTML。

### 文件结构

- `dist/index.html`：网页入口
- `dist/`：完整静态网站，包括脚本、样式、字体、图片和视频
- `server.mjs`：本地预览服务器，支持视频分段请求
- `tests/`：交互状态与页面布局测试

验证命令：`node --test tests/*.test.mjs`。

部署时将静态站点目录设置为 `dist`，无需构建。项目中的个人资料与作品仅用于个人作品集展示。
